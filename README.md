# NLP_2025
**This repository contains assignments and projects from the Natural Language Processing (NLP) course in 2025.** All work is implemented in Python using Jupyter Notebooks and primarily executed via Google Colab for ease of computation and collaboration.

## Contents

- 📚 Weekly tasks  
- 🧪 Experiments and hands-on text data processing  
- 🧠 Midterm implementation project focused on real-world NLP use cases  
- 🔧 Utilization of NLP libraries including NLTK, spaCy, etc.

## Purpose

This repository serves as a personal learning log and implementation portfolio for key NLP concepts, including text preprocessing, model development, and performance evaluation.
